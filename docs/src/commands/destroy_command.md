# destroy

This command destroys virtual machines and cleans up configuration artifacts.
It supports destroying single nodes, entire configurations, or resources across multiple cloud providers.

You must provide the following parameters to the command:

* Path to the configuration directory or a specific node (e.g., `vms/rhel_10/node01`)
* OR use specific flags to filter by cloud instance names or lists

### Options

* `--all`
  Destroys all configurations found in the specified directory path.
* `--json [path]`
  Destroys instances listed in the specified JSON file (generated by `list_cloud_instances`).
* `--node-name [name]`
  Destroys instances matching the provided name or regex across all providers.
* `--list`
  Lists all active VMs from Vagrant, AWS, GCP, IBM Cloud, and DigitalOcean without destroying them.
* `--public-network-name [name]`
  Specifically destroys the IBM Cloud public network with the given name.
* `--keep-template`
  Prevents the deletion of the template file associated with the configuration.
* `--force`
  Removes interactivity, assuming 'yes' for all confirmation prompts.
* `-l, --labels [labels]`
  Filters VMs to destroy based on labels (comma-separated, no spaces).

### Examples

Destroy a specific node:
```bash
mdbci destroy vms/rhel_10/node01
```

Destroy all nodes matching a regex pattern:
```bash
mdbci destroy --node-name "node0.*"
```


Destroy all configurations in a directory:
```bash
mdbci destroy --all vms/
```

### Details

* For Vagrant configurations, it removes the VMs and associated files.
* For Terraform configurations, it runs `terraform destroy`.
