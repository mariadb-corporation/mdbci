# clean-unused-resources

This command destroys unused cloud resources (instances, disks, security groups, key pairs, public networks) based on a JSON report file.
This report file is typically generated by the `list-cloud-resources` command.

You must provide the path to the resource list file using `--resources-list`.

### Options

* `--resources-list [filename]`
  (Required) The path to a JSON file containing the list of resources to destroy.
  The file must follow the structure generated by `list-cloud-resources`.

### Example

Destroy the resources listed in `unused_resources.json`:
```bash
mdbci clean-unused-resources --resources-list unused_resources.json
```

### Details

* **Safety**: This command performs destructive actions. Ensure the JSON file contains only the resources you intend to delete.
* **Supported Resources**:
  * AWS: EC2 instances, EBS volumes, Security Groups, Key Pairs.
  * GCP: Compute instances, Disks.
  * IBM Cloud: Compute instances, Public Networks.
* **Process**:
  1. Parses the JSON file.
  2. Iterates through instances, disks, and other resources.
  3. Calls the respective cloud provider APIs to terminate/delete resources.
  4. Reports success or failure for each operation.
